原文要点

10 月 14 日起在 ChatGPT、ChatGPT Work、Codex 全计划告别 GPT-5.5；Codex 用户请改用 GPT-5.6 Sol 或 GPT-6 Astra。同窗口 OpenAIDevs 补充：OpenAI API Platform 与「用 API key 登录的 Codex 会话」仍可继续用 5.5。

对企业/增效意味着什么

这是典型的模型生命周期运营：盘点（1）Work/Codex 默认模型与自定义 agent；（2）定时任务与模型脚本；（3）员工「已习惯的 5.5」切换沟通。API 路径与订阅路径分叉——平台工程要写清「哪些工作负载必须锁模型版本」。迁移窗口约一个月，别拖到 10/14。

舆论/讨论

抽样：（1）「AI model years = dog years」；（2）中文圈「傲慢退役」与「5.5 太拉」并存；（3）日文猜测 Astra 会进聊天。管理启示：退役沟通要给替代路径与评测对照。
