[@emollick] Claude 无图像生成：知识工作 agent 的缺口

原文要点

Claude 没有图像生成器，是涉及知识工作的 agentic 项目缺口。擅长用代码画图/建模，但 Google 与 OpenAI 的图像生成让自家 AI 在做 PowerPoint、mockup、信息图时选项更多。续帖：接 API 可补一部分，但多数人不会、有额外费用，且真正增益来自 Omni 多模态——Claude 在此最弱。

对企业/增效意味着什么

办公自动化选型把「幻灯片/示意图闭环」列入验收；若 Claude 为主脑，默认编排 Gemini/OpenAI 生图节点并预估成本；IT 提供一键多模态模板降低落地税。

舆论/讨论

日文：资料跨工具=时间成本；有人说「一个 plugin 就能补」；另有「不会做 mock 的 agent 还没开讲就丢会议室」。

[@emollick] 长跑 agent 最烦人的是 文风漂移

https://x.com/emollick/status/2101731295659180527 · 2026-09-21 01:52 · 👍 264 · ↻ 8 · 💬 56 · 引用 5 · 展示约 2.6 万 · 书签 33 · 另有续帖

原文要点

长时程 agentic 任务最恼人的已不是编码错误或幻觉，而是语言因 drift 变差。续帖：已有 voice.md、读者代理终审、反 LLM 腔代理、同族多模型交叉——仍不够。

对企业/增效意味着什么

长文档流水线设中途重锚定；验收加音色一致性抽检；别指望提示词堆叠一劳永逸——漂移常是状态漂移。

舆论/讨论

英文：长上下文稀释注意力，退化输出再进上下文；「请别把简单答案写成董事会备忘录」。日文：想越久，话越糙。
