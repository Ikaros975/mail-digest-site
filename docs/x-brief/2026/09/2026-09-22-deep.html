原文要点

过去两周「AI 危险」恐惧被大声放大，更像有组织公关/炒作，而非技术突然变危险。灭绝风险相对数月前并无实质台阶；更值得严肃对待的是网络安全。OpenAI 团队用 agent 群攻破 Hugging Face 的报道常被神化。关键是 buggy 沙箱与监测——应修工程，而非暂停 AI。不要把 LLM/agent 拟人化：锤子砸墙责任在用锤子的人。暂停十年只会让对手不停，并推迟发现与修复安全问题。

对企业/增效意味着什么

风险委员会材料区分「灭绝叙事 / 网络攻防 / 产品安全工程」；采购 agent 平台把沙箱、审计、人类授权写成验收；出事后追责建设者与使用者，而非「agent 失控免责」。

舆论/讨论

引用侧赞 Andrew Ng「信号噪声比十年保持高」；中文：「真做研究的人不信煽动」；有人提醒「政策≠控制——autonomy 前要可检查的权限边界」。
