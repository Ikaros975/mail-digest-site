一、执行摘要（先看结论）

默认还是 Temu——前提是现金和职级谈得下来。
和 Shein 经验同构，跨境赛道也符合「别再纯干国内物流」，组织成熟，历史上挖人肯给溢价。代价也清楚：强度大、细节密，很难指望在这里遇到「有战略远见的领导」。

京东物流当备份，说服力弱。
牌子稳、体系稳，但主业还是国内仓配 / 一体化供应链，跟「不想再做国内物流」直接撞车。流程细、盯细节多，对「换领导风格」帮助有限。

阶跃星辰是有条件才碰的跃迁牌，不是无条件优选。
公司层「AI+终端 / STEPX」讲得清楚，公开端已有深圳供应链物流 / 订单高薪挂价，也和「三人建物流」的口述对得上。但量产和零售履约还没落地，物流 #3 很容易变成高负荷建制工。
只有这几条同时成立，才值得压过 Temu：现金不显著吃亏、期权说得清、直属 lead 授权清楚、量产时间表能验证。

二、阶跃是否合适 / 为什么

结论：有条件合适（Conditional Yes）。
当成「补管理履历 + 做 AI 硬件履约」的跃迁牌；条件不过线，就不合适。

你缺的是管理故事、从 0 到 1 的建制经历——阶跃物流 #3 理论上能补。
你要的是战略型领导和更确定的现金——公司叙事层看着像，直属和薪酬必须尽调坐实；坐不实，还是 Temu 更贴你已经说清楚的偏好。

合适与否，不看公司酷不酷，看三条是否同时过线：offer 条件 + 直属 + 量产里程碑。

  • 2026-07 发了 STEPX / Step AOS / Amoo / STEPX Neo，方向是自有品牌硬件 + 模型闭环。
  • 有 华勤 等 ODM 资本绑定，合作出货偏「共建」叙事。
  • 猎聘公开线索：深圳供应链物流 / 订单，挂价约 40–70k · 16 薪。
  • 做成了，简历多一块稀缺标签；做不成，窗口可能只有 12–24 个月。

理由 2 — #3 到底意味着什么

早期职能第 3 人，典型是 doer / leader 混岗：SOP、3PL、异常、对账，有时还要兼招人。

  • 上行：业务放量 + lead 让你承包一块 + 期权。
  • 下行：量产拖、lead 抠细节、你长期像高级跟单、权益兑不了现。

现金数字都是公开 / 二手区间，不是 offer 承诺；2026 Temu 精确总包 unknown。阶跃的「战略感」来自公司叙事和 JD「0–1 搭建」，直属放权还没验证。VOC 置信度大约 0.45。

CASH · 主选

Temu

  • 现金主选：历史高溢价挖人，最贴「更高薪」；当面把级别和总包锁死。
  • 和 Shein 经验同池，跨境赛道符合「离开纯国内物流」。
  • 2022 曾见招商约 20–40k×14、物流商务高档二手报道；2026 精确 unknown。
  • 强度高（「11116」等长期标签）；细节密度高；抠细节冲突风险最高（拼多多系高压盯数口碑）。
  • 下一跳：跨境平台 / 货代 / 海外仓负责人。
BACKUP · 慎选

京东物流

  • 保底慎选：雇主品牌和上市体系稳，但主业仍是国内仓配——跟「厌国内物流」直接撞车。
  • 顺丰 仓配经验可迁移；专项岗现金可高于白领均值，一线涨薪有限。
  • 权益相对清晰；强度中高；细节密度高（标准运营）；战略感弱。
  • 近窗原声多在历史牛客仓帖；一手吐槽偏一线 / 大促高压。
  • 下一跳：3PL / 品牌供应链 / 区域管理——只有特定非一线国内运营岗才值得浅谈。
CONDITIONAL · 跃迁

阶跃星辰 物流 #3

  • 条件跃迁：1 lead +1 +你，从 0–1 建制；能补「非管理」短板，但 grind 极重。
  • 深圳挂价约 40–70k×16（另见 25–50k×16 档）；实拿 unknown，很难直接拼 Temu 的现金故事。
  • 创业期权潜力大、兑现不确定；成败绑在硬件量产（STEPX）。
  • JD 明文要 0–1 搭建；lead 放不放权，面试里当面探针；细节密度极高。
  • 下一跳：品牌供应链 / AI 硬件物流头 / 或回流跨境。

简表结论

  • 要钱 + 熟赛道 + 能扛强度 → Temu（现金主选）
  • 要稳 + 不在乎国内物流标签 → 京东（保底慎选；和口述偏好矛盾，备份价值低）
  • 要跃迁管理 + AI 硬件故事 + 能接受不确定 → 尽调过线后的阶跃（条件跃迁）

VOC 收口：阶跃「第 3 人有潜力」在招聘文案上说得通，但社区口碑验证不了老板风格。Temu 的钱最合动机，管理风格是最大性格风险。京东作 backup，和画像双重背离。

四、若选阶跃：尽调问题清单

A. 业务与量产（一票否决区）

  1. STEPX / 相关硬件 预计首销时间、首年出货或履约单量的内部区间？
  2. 渠道结构：官网直销 / 电商 / 运营商 / 线下？谁背库存？
  3. 未来 12 个月物流预算是否已批？
  4. 若量产推迟两个季度，物流编制的保底任务是什么？会不会裁？

B. 组织与 #3 角色

  1. 现在物流编制完整名单与分工（lead / 另一人 / 你）？深圳是否常驻？
  2. 入职 90 天的 唯一主人翁模块 是什么（仓 / 干线 / 逆向 / 订单 / 成本）？
  3. 12 个月后编制规划？是否被期望带人？职级与晋升通道？
  4. 成功标准：看哪些 KPI（时效、破损、成本占比、客诉）？谁定目标？

C. 直属领导风格

  1. Lead 的上一份工作与管理人数？请举一个他 主动不做、交给下属闭环 的例子。
  2. 周会形态：对异常是「一起定原则」还是「逐单抠」？
  3. 与产品 / 供应链 / 客服的决策升级路径？是否允许直接对外签 3PL 日常单？

D. 薪酬与权益

  1. 现金总包结构：月薪、月数、签字费、绩效规则；与猎聘 40–70k×16 的对应职级？
  2. 期权/限制性股权：授予数量或价值口径、行权价、归属表、离职处理、是否有回购？
  3. 若只比现金，相对 Temu 同级差多少？公司用什么补？

E. 风险与退出

  1. 硬件若收缩，内部是否有其他供应链/运营坑位？
  2. 试用期考核书面标准？
  3. 能否提供一位同阶段加入的非算法同事作 reference chat？

五、建议决策流程（含决策规则）

并行推 Temu 和阶跃。 京东只在岗 JD 不是「国内一线运营」时浅谈。

  1. 两边都拿到现金总包数字
  2. 阶跃做完「量产 + lead 授权 + 期权」三问
  3. 决策规则：
    • 阶跃三问全过，且现金 ≥ Temu 的约 85% → 选阶跃
    • 任一三问不过，或现金明显低 → 选 Temu
    • Temu 强度受不了，阶跃也不过线 → 重新开搜（消费电子品牌供应链 / 跨境头程物流负责人），别硬接京东国内运营

执行摘要

阶跃星辰是 2023 年 4 月在上海徐汇成立的通用大模型公司，品牌名 StepFun，法定主体现为 上海阶跃星辰智能科技股份有限公司。创始人兼 CEO 是 姜大昕（前微软全球副总裁）；2026 年 1 月 印奇（旷视联合创始人、千里科技董事长）出任董事长，和首席科学家 张祥雨、CTO 朱亦博 组成核心决策层。公司常被归入中国大模型「六小虎 / 六小龙」。产品主线是 Step 系列（语言 / 多模态 / 音视频 / Flash Agent）+ 开放平台 API，应用侧有跃问（阶跃 AI）等；战略主轴明确写成 「基础大模型 + AI+终端」。

STEPX / Step AOS 体系中的系统级个人智能体：强调环境感知、复杂任务拆解与跨 App 工具调用，而非传统单轮聊天助手。

来源：知乎专栏产品解读 · 安兔兔资讯

STEPX Neo

STEPX 品牌首款智能体手机样机；搭载 Step AOS 与 Amoo，媒体报道称其通过首批人工智能终端智能化分级相关测试。

来源：电子工程专辑 · 上观新闻

Temu

PDD Holdings（拼多多母公司）旗下跨境电商市场平台，面向海外以低价商品为主；常被拿来与 Shein 对标竞争。

来源：Wikipedia: Temu · Business of Fashion

拼多多 / PDD Holdings

中国社交电商巨头；母公司 PDD Holdings 同时运营国内拼多多与海外 Temu。社区职场口碑常与高强度执行文化绑定。

来源：Pinduoduo EN 简介 · Wikipedia: Temu

Shein（希音）

以快时尚服饰出海闻名的独立跨境电商品牌/平台，与 Temu 无股权关系；物流与供应链人才池常被 Temu 对标挖人。

来源：BBC：Shein 赴港上市报道 · Temu vs Shein 说明

京东物流

京东集团分拆并港交所上市的综合物流公司，以仓配一体与供应链服务见长；国内一线仓配与职能岗口碑分化明显。

来源：Law.asia 上市报道 · 京东物流「超脑」新闻

华勤技术

总部上海的全球智能产品 ODM/平台型企业，为品牌客户提供手机等消费电子端到端设计与制造；公开报道亦出现在阶跃融资/产业合作名单中。

来源：华勤官网 · 华勤公司介绍

Token（词元）

大模型处理文本的基本计费与计算单元（词/子词/字符片段）。API 常按百万 Token 计价；「调用榜」亦常以 Token 用量衡量模型热度。

来源：Microsoft Learn: Understanding tokens · OpenRouter models pricing

VOC（Voice of Customer / 舆论原声）

系统收集并分析客户/用户原声与反馈的方法；本备忘中亦泛指社媒与职场社区对雇主/产品的舆情抽样。

来源：Qualtrics: What is VoC · Salesforce VoC guide

MoE（Mixture of Experts）

混合专家架构：用路由把输入分给不同专家子网络，从而在总参数很大时只激活部分参数，兼顾容量与算力。Step / DeepSeek 等 Flash 模型常用此路线。

来源：DeepSeekMoE arXiv · DeepSeek MoE GitHub

DeepSeek（深度求索）

中国大模型公司，以开源/高性价比与调用量著称；本窗口社区常把其 Flash 系列当作「便宜够用」的默认对照，并曾挤占周 Token 榜头部。

来源：OpenRouter DeepSeek · 腾讯云：六小龙现状文

OpenRouter

统一 API / 路由市场：开发者可通过单一接口调用多家模型并比较价格与上下文；社区常引用其标价与免费池收录情况。

来源：Codecademy: What is OpenRouter · OpenRouter models

Apache License 2.0

宽松开源许可证：允许商业使用、修改与再分发，需保留版权与许可声明。阶跃 Step 3 / Flash 等权重常以此许可开源。

来源：Apache License 2.0 (OSI) · Apache Software Foundation licenses

MCP（Model Context Protocol）

Anthropic 提出的开放标准，用于标准化 AI 应用与外部数据源/工具的双向连接；Agent 生态活动常与 MCP 同台出现。

来源：Anthropic: Introducing MCP · Wikipedia: Model Context Protocol

Agent / 智能体

能围绕目标规划、调用工具、观察结果并迭代完成任务的 AI 系统；「Agentic」强调可行动、可编排，而不只是单轮对话。

来源：MIT Sloan: Agentic AI explained · Anthropic MCP intro (tool use context)

大模型「六小龙/六小虎」

媒体对中国一批聚焦大模型的创业公司的统称，常见名单含智谱、MiniMax、月之暗面、阶跃星辰、百川智能、零一万物；随后格局持续分化。

来源：百度百科：AI六小龙 · 财新深度专题

智谱 AI

中国大模型「六小龙」之一，以 GLM 系列与相对更早的资本化/上市叙事见长；社区常将其放在「聪明旗舰」对照轴。

来源：百度百科：AI六小龙 · 证券时报：六小龙报道

MiniMax

中国大模型公司，属「六小龙」阵营；本窗口常与阶跃同框出现在「跌出周 Token 调用榜」类财经转载中。

来源：财新 AI 六小虎专题 · 腾讯云六小龙现状

Kimi / 月之暗面

月之暗面（Moonshot）旗下 C 端助手品牌；社区心智上常占「聪明旗舰/长上下文」话术，与 Step 的 Flash/Agent 定位形成对照。

来源：证券时报六小龙 · 财新专题

知识蒸馏（Knowledge Distillation）

把「教师」大模型的能力迁移到更小「学生」模型的训练技术。2026-09 美方通报语境中，亦被用来指控对中国实验室的工业化模型提取行为。

来源：Adaline Labs: LLM Distillation Explained · Emergent Mind: distillation token

千里科技

印奇担任董事长的上市公司主体，强调智驾/车端叙事；与阶跃的「车×模型」协同常被媒体并提。

来源：央广网人事报道 · 观察者网

3PL（第三方物流）

企业把仓储、履约、运输、退货等物流环节外包给专业第三方服务商；硬件创业物流岗常需考核与管理 3PL。

来源：ShipBob: What is 3PL · Cin7 3PL guide

OTD（On-Time Delivery）

准时交付率：衡量订单是否按承诺时效送达的关键履约 KPI，常见于供应链与物流团队的成功标准。

来源：DCL: 3PL SLA 指南 · ShipBob 3PL overview

SLA（Service Level Agreement）

服务水平协议：约定时效、准确率、破损率等可量化承诺与违约后果；物流岗常据此考核货代/3PL。

来源：DCL: What to look for in 3PL SLA · ASC Software: What is a 3PL

WMS（Warehouse Management System）

仓库管理系统：覆盖收货、上架、拣选、库存与出库等仓内作业；京东等大平台仓配体系的核心系统之一。

来源：Finale: 3PL WMS · ASC Software 3PL

ODM（Original Design Manufacturer）

原始设计制造商：不仅代工生产，还参与产品设计与整机方案；华勤等是消费电子 ODM 代表。

来源：华勤官网 · 华勤手机平板业务

API

应用程序接口：系统间按约定请求/响应互操作。大模型商业化常见「按 Token 计费的模型 API」与更高层 Agent/工作流产品。

来源：OpenRouter API overview · Microsoft Learn tokens（计费语境）

Flash（模型档）

厂商对「更快/更便宜/面向生产 Agent」档模型的常见命名（如 Step 3.5/3.7 Flash、DeepSeek V4-Flash）；强调吞吐与性价比而非唯智商榜。

来源：OpenRouter DeepSeek Flash · 华尔街见闻阶跃融资文（产品语境）

ResNet

深度残差网络，计算机视觉里程碑架构；媒体介绍张祥雨时常用「ResNet 作者之一」作为学术标签。

来源：观察者网通稿表述 · 品玩：旷视团队回顾

顺丰速运

中国主要综合物流/快递企业之一，以时效件与中转网络见长；常与京东物流并列为国内物流雇主品牌对照。

来源：钛媒体：京东物流与顺丰对照 · Law.asia 京东物流上市

跃问 / 阶跃 AI

阶跃星辰主 C 端助手产品线；战略叙述从对话助手走向任务型 Agent，并与桌面伙伴等形态并存。

来源：华尔街见闻公司报道 · 观察者网

WAIC（世界人工智能大会）

在上海举办的大型人工智能产业展会/论坛；阶跃等公司常借 WAIC 发布模型、终端或生态合作。

来源：证券时报 WAIC 六小龙报道 · 电子工程专辑 STEPX

GTM（Go-To-Market）

走向市场策略：产品如何定价、渠道、销售与增长落地。本备忘中「硬件 GTM / 物流编制」指终端量产前后的履约与组织准备。

来源：Qualtrics VoC（客户反馈驱动 GTM） · Salesforce VoC program

SOP（标准作业程序）

Standard Operating Procedure：把重复工作写成可执行标准步骤。早期物流 #3 常要共建仓配/异常/对账等 SOP。

来源：ShipBob 3PL processes · ASC Software 3PL ops

KPI（关键绩效指标）

Key Performance Indicator：用可量化指标衡量业务结果。物流常见时效、破损、成本占比、客诉等 KPI。

来源：DCL SLA/KPI 语境 · Qualtrics 客户体验指标语境
