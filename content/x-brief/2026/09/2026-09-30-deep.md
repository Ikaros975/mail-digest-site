## TLDR（给管理者）

1. **常驻 agent 产品化**：OpenAI 发布 Dots（GPT-6 Astra），自有云电脑、可连 4000+ 应用，可在 ChatGPT/Slack/Teams 触达；Pro/Business Premium 首枚含在订阅内，Enterprise 需管理员开 beta。采购与安全要立刻定「自主边界 / 审批 / 连接应用清单」，别把「永远在线」当成默认全开。
2. **中档近旗舰、单价大砍**：GPT-6.1 Sol 官方称近 Astra、约 1/5 价；缓存输入约 $0.10/MTok。默认路由应重跑「日常 coding / 专业工作」评测——别再默认全员 Astra。
3. **速度成为付费档**：Ultrafast 在 Codex 最高约 8×（约 300 tok/s）、API 约 6×；配套 Pro 500（约 25× Plus）。要区分「需要低时延的交互回路」与「可批处理的云端任务」，避免全员升档。
4. **协作面扩到 Space 与即时通讯**：ChatGPT Space（pages）+ Slack/Teams 内 @ChatGPT——企业工作流从「个人开 ChatGPT」变成「线程里共创」。治理重点：工作区授权、无个人许可证参与、连接源审批。
5. **编码 agent 可关盖续跑 + 安全默扫**：Codex 云环境 + Security Cloud（Daybreak Blue 默认）把「人离开后任务仍推进」与「仓库持续审」打包进平台——变更管理与密钥边界要一起设计。
6. **别被新品名淹没**：Mollick 指出 Dot/Spaces/Pages/Work/定时任务边界混乱，且第三方生态年年换壳（Plugins→GPTs→Apps→Plugins）。内部发布清单应映射「唯一职责」，对生态投资设退出条件。
