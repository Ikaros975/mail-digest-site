# 姜学长x@AI TIME : 和清华AIR赵昊老师@Fromandto赵昊 访谈播客切片ep2: 为什么AI不能像人一样预测物体的软硬及抓取

## 一句话概括
AI抓东西不会“捏一捏”探软硬，缺的是人手那套世界模型。

## 核心内容（注：原视频仅2分29秒，信息量有限，以下按实际内容展开）

**背景与问题提出**：赵昊老师指出，人之所以能抓取任何东西，关键在于人能在接触的“头几帧”通过视觉流（sing flow）非常快地预测出物体有多软、有多硬。这个能力远比想象的更重要——因为仓储场景是典型的“pick and place”场景，看似简单，但最难的地方在于：如果物体太硬或太软、抓取策略不对，连 pick and place 都做不成。而仓储场景一旦sku数量达到400万级别，这件事就非常难。赵老师提出的替代方案是“建一个知识库”，但随即自我否定：“建一个知识库就不太AI了”。（解读：知识库是穷举式工程手段，不是智能本身。）

**人的机制——世界模型**：那人是怎么办到的？人其实在接触到物体那一瞬间，大概就知道它有多软多硬；如果是软的，就多抓一下、多捏住一下。赵老师点明本质：人其实是有一个**世界模型**的，能对未来视觉流（sing flow）做预测。这个“非常小点的case”在端到端过程中被发现非常有效。所谓世界模型，就是人在抓400万个sku时，有能力预测物体未来的4D变化——比如捏它以后它会瘪多少，这个过程叫“斯蒂森测”（注：按字幕原文记录，疑为情境/状态测量之音译）；如果你能预测它会捏到什么程度，说明你脑子里有个世界模型。

**架构落地**：赵老师把这个想法落到了自己的架构上，即“ford word action model”，包含有 point map 的 3D token，以及 sing flow 的 4D token。（解读：即把静态3D几何与动态4D变形预测联合建模，再映射到动作输出。）

**工具使用——更高的挑战**：通用具身智能肯定不只是物体的简单抓取。赵老师认为最难的是“tour using”（按原文记录，指工具使用），现在大家展示的灵巧操作（dexterous manipulation）还停留在超越 pick and place 的层面，尚未涉及复杂工具。而人会使用大量工具——剪刀、各种厨具、各种工业工具、笔、所有家具，甚至车本身也是工具。使用工具同样需要世界模型：你需要知道使用工具与世界交互过程中，工具怎么变化、工具的 sing flow 是什么样子、工具上每一个点的加速度是什么样——因为加速度和力直接耦合——以及物体会怎么变化。

**关键结论**：抓取的核心不是“抓住”，而是“预判”——预判软硬、预判形变、预判工具与物体的未来4D演化。缺乏世界模型的AI，抓取只是盲抓。

## 记忆锚点（3-5条）
- 【捏一捏】人抓东西先“捏一捏”探软硬，AI抓东西只会“盲抓”——差的就是脑子里的世界模型。
- 【400万SKU的知识库悖论】想靠建知识库解决400万SKU的抓取？赵老师一句话点破：“建知识库就不太AI了”——穷举不是智能。
- 【4D token翻译官】3D token 记住“长什么样”（point map），4D token 预测“会变成什么样”（sing flow），合起来才是会预判的手。
- 【工具即世界的延伸】剪刀、厨具、笔、车都是工具，用工具就得预测工具上每一点的加速度——加速度和力直接耦合。

  - **解读**：做具身智能抓取，第一优先级不是手部硬件，而是形变预判模型。

- **要点二：人靠世界模型，AI缺这一块**
  - **原文引用**：「你人其实在接触到那一瞬间，你大概就知道它有多软和多硬」
  - **案例还原**：赵老师还原了人的行为链：接触瞬间判断软硬→如果是软的就多捏一下、多抓一下。他点明这背后是“世界模型”——人能预测未来的视觉流变化，捏下去它会瘪多少（斯蒂森测），能预测到这个程度，说明脑子里有世界模型。这个“非常小点的case”在端到端流程中被发现非常有效。
  - **解读**：世界模型不是宏大叙事，先从“捏下去会瘪多少”这种小预测做起。

- **要点三：架构上怎么落地——3D+4D token**
  - **原文引用**：「有point map的3D token，还有这个sing flow的4D token」
  - **案例还原**：赵老师把自己团队架构称为“ford word action model”，用 point map 的 3D token 表征物体空间几何，用 sing flow 的 4D token 表征随时间演化的形变与运动，再输出动作。这是把“人的世界模型”工程化的具体尝试。
  - **解读**：做具身智能的团队可参考“静态几何+动态演化”双流建模思路。

## 三大职业视角洞察

### ① 市场调研 & 用户研究
- **新洞察**：赵老师对“建知识库”的否定，本质上是对“穷举式需求覆盖”的否定——400万SKU不可能一个个调研打标签。这对用户研究是直接警示：靠堆样本量、堆标签库去覆盖长尾，不如建立能预测新场景的“用户世界模型”。
- **可借鉴方法**：人的“接触瞬间判断软硬”提示了一种研究范式——关注用户在**首次接触的最初几帧**形成的直觉判断，而非长期问卷回溯。做可用性测试时，前几秒的行为数据可能比事后访谈更有价值。
- **被揭示的坑**：把“知识库”当成智能，是调研中常见的伪解法——收集了一堆用户标签，却无法预测用户面对新品类时的行为。

### ② 品牌推广 & 营销
- **新营销思路**：本视频是学术访谈切片，营销侧的直接素材有限，但“sing flow——头几帧预测”这一概念可迁移为传播逻辑：用户对品牌的判断也发生在接触的最初几帧，内容的前3秒决定软硬印象（解读/推论）。
- **值得研究的传播路径**：赵老师用“人捏东西”的日常经验解释世界模型，这种**用生活直觉翻译技术概念**的表达方式，本身是极佳的技术品牌内容模板——把抽象架构（3D token/4D token）降维成“捏一捏会瘪多少”。

### ③ 电商运营
- **运营策略参考**：仓储场景与400万SKU是电商运营的直接语境。赵老师指出 pick and place 在SKU爆炸后失败的原因是“软硬判断错→抓取策略错”，映射到电商即：**长尾SKU的履约策略不能一刀切**，包装、分拣、推荐都需要按品类物理属性（软/硬/易碎）分层（解读/推论）。
- **转化路径新发现**：视频未涉及用户转化路径的具体内容，不做延伸。

### ④ 智能硬件 PM（AI时代新定义）
- **AI能发挥作用的阶段**：按赵老师的架构思路，AI目前在**感知与动作策略阶段**已有清晰路径——通过 point map 的 3D token 做几何理解、通过 sing flow 的 4D token 做形变预测，再端到端输出抓取动作。这提示硬件PM：AI在“物体物理属性预测→动作参数生成”这一环是能真正落地的。
- **AI的边界**：赵老师明确点出两处边界——其一，“建知识库就不太AI了”，穷举式规则库不是智能，PM不能指望用数据集堆死长尾；其二，复杂工具使用（剪刀、厨具、工业工具）目前仍是空白，灵巧操作尚未超越简单抓放。此外，ID设计、MD堆叠、电子设计前期demo在逐字稿中**完全未涉及**，不能据此推断AI在该流程中的能力（严格约束）。
- **流程与岗位信号**：赵老师团队架构中出现“ford word action model + 3D token + 4D token”这类命名，说明具身智能团队正在把“世界模型”作为独立模块纳入产品架构——PM在定义新一代硬件时，可能需要把“形变预测能力”作为一项可验收的产品指标，而非笼统的“智能抓取”（解读/推论）。
